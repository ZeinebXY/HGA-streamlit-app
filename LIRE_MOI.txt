Projet ordo — HGA + Gurobi (Streamlit)
======================================

Structure
---------
  App.py              application Streamlit (à lancer)
  ordo/               code : hga.py, instance.py, milp_gurobi.py, experiments.py
  Solver/             instances Data_*.txt (dont Data_2_8_2)
  .streamlit/         thème clair uniquement (pas de 2e App.py)

Lancement
---------
  cd projet_final
  pip install streamlit pandas altair gurobipy   # gurobipy optionnel pour Z* exact
  streamlit run App.py
